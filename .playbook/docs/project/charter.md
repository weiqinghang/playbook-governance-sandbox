# 项目宪章

本文件是目标仓自己的项目宪章模板。安装 seed 后，应由目标仓团队用本仓真实目标替换占位内容。

## 北极星

- 待填写：这个仓库长期要服务的用户、工作流或业务目标。

## 长期约束

- 待填写：目标仓的技术、协作、权限、成本、交付和质量约束。

## 当前使命

- 待填写：当前阶段最重要的 1-3 个目标。

## 非谈判规则

- 目标仓的原生 Issue/PR/MR 平台是任务状态事实源。
- 关键共识、设计决策、handoff、成功模式和 badcase 不能只停留在聊天中。
- 没有验证证据，不宣称完成。

## 这不是一个什么项目

- 待填写：最容易被误解或误纳入范围的非目标。

## 完成定义

- 目标平台工作项状态已更新。
- repo 中必要工件已更新。
- 验证证据存在。
- 如产生可复用模式或 badcase，已进入目标仓约定落点。
